# Code Aw Icons

A lightweight, minimalist SVG library & icon finder.

Open `index.html` in your browser. No installation or dependencies are needed.

Search by name, filter by category or style, and click an icon to copy its SVG. You can also download icons, adjust their size, color, and thickness.

- `index.html`: page structure
- `assets/styles.css`: design and animations
- `scripts/icons.js`: icon library
- `app.js`: search, filters, customization, and exports
